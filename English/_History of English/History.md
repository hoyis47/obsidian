
##  - 영국 역사와 언어

1. Celts 켈트족 시기 : London, Thames지명
	1. ~ 5세기 
	2. Britania에서 살고있음 -> Britain의 기원
2. 로마 제국 지배 : 요새와 도로건설 -chester지명(맨체스터)
3. 고대언어 : Anglo-Saxon족 시기
	1. 5~11세기
	2. 북서유럽의 게르만족 일부가 브리튼섬으로 이주
	3. 앵글로 색슨어 형성 -> 앵글로족의 언어 : English, 앵글로족의 땅 : England
	4. 영국 동부 차지, 나머지는 Wales, Scotland, Ireland로 쫒겨남
	5. 8~9세기 바이킹(노르드인) 침략으로 노르드어 섞임(they, give, take, sky)
4. 중세언어 : 프랑스어(노르만어) 유입
	1. 11~15세기
	2. 노르만 정복(1066년) : 프랑스 노르망디 공작 빌리엄(William) 영국 정복
	3. 이중 언어 : 귀족은 프랑스어, 평민은 고대영어
	4. 어휘 분화 : 평민의 영어 cow, pig, sheep, 귀족영어 beef, pork, mutton
5. 근대언어 : 대모음 변이, 인쇄술, 르네상스(라틴어유입)
	1. 15~19세기
	2. 대모음변이(Great Vowel Shift) : 14~17세기 장모음 발음 크게 바뀜, 철자는 고정되고 발음바뀌며 철자와 발음의 불일치현상의 원인이 됨
	3. 인쇄술, 세익스피어 : 인쇄술로 런던 방언 중심의 표준어휘, 철자 정착, 세익스피어가 수천개의 새로운 단어와 표현을 창작, 르네상스 시대 라틴어와 그리스어 대량 도입
6. 현대영어 : 세계화, 글로벌언어
	1. 19세기 ~
	2. 대영제국 식민지확장, 미국의 영향으로 공영어
	3. 지금도 어휘는 끊임없이 변화중



## - 영어 유래에 따른 어휘 구조

1. 게르만어(Anglo-Saxon) 
	1. 26%
	2. 일상어 기초어휘 감정 신체
	3. 짧고 직관적, 생활 밀착형
	4. 문법구조이루는 기능어(전치사, 대명사)
	5. house, water, sun, eat, hand, heart, mother, sleep, live, cold, good
2. 프랑스어(French/Norman)
	1. 29%
	2. 정치, 법률, 고급문화, 요리, 패션
	3. 중세 노르만 정복이후 귀족층이 사용하던 어휘
	4. 세련되거 정제된 느낌의 단어
	5. court, government, royal, cuisine, beef, fashion, art, justice, Liberty
3. 라틴어(Latin)
	1. 29%
	2. 학문, 종교, 법률, 공식문서, 기술
	3. 르네상스 및 학술적 연구를 통해 유입
	4. 논리적이고 객관적인 느낌을 주는 격식체
	5. educate, legal, describe, vacuum, maximum, intelligence, include
4. 그리스어(Greek)
	1. 6%
	2. 과학, 철학, 의학, 예술이론
	3. 접두사와 접미사 결합형태가 많음
	4. geography, philosophy, psycology, democracy, atom, rhythm
5. 노르드어, 기타
	1. 10%
	2. 바이킹 침략시기의 일상어(노르드어) : sky, take, give, skin, Window
	3. 세계 식민지 개척으로 유입된 글로벌어휘: tea, chocolate, coffee, piano


**유래에 따른 3단계 어휘 층위 (3-Tier Vocabulary)**

같은 의미를 지닌 단어라도 게르만어 유래 → 프랑스어 유래 → 라틴어 유래로 올라갈수록 더 공식적이고 학술적인 뉘앙스를 가집니다.

- **"끝내다"**: _Ask_ (게르만 - 일상) ➔ _Question_ (프랑스 - 격식) ➔ _Interrogate_ (라틴 - 전문/법률)
    
- **"시작하다"**: _Start_ (게르만) ➔ _Begin_ (게르만) ➔ _Commence_ (프랑스/라틴)
    
- **"도움"**: _Help_ (게르만) ➔ _Aid_ (프랑스) ➔ _Assistance_ (라틴)
    
- **"왕의 / 고귀한"**: _King side / Kingly_ (게르만) ➔ _Royal_ (프랑스) ➔ _Regal_ (라틴)



## - 정리

#### 사전 속 전체 어휘
프랑스어, 라틴어 (60%) > 게르만어 (26%)

#### 일상언어(말)
게르만어(80~90%) > 프랑스어, 라틴어(10~20%)


## - Weak Verb, Strong Verb

#### 분류
weak verb : 게르만 계열의 구어체 동사
strong verb : 프랑스어 계열의 문어체 동사

#### weak verb 사용법

1. weak verb는 약한 의미를 보강하기 위해 결합한다.
	1. weak verb + 전치사, 부사 
		1. go out, put down, put in
		2. 구동사
		3. 방향/완결
	2. weak verb + 형용사 
		1. go bad, get dark
		2. 2형식
		3. 상태의 변화
	3. weak verb + 명사 
		1. take a break, make a call
		2. 기능동사
		3. 행동의 실행
	4. weak verb + 준동사(to부정사, -ing, p.p)
		1. get him to go, make it work
		2. 5형식
		3. 사역/유도
	5. weak verb + 장소/상태부사
		1. get home, go abroad
		2. 1형식
		3. 이동/도달

2. 구동사의 대명사 위치제약 : 대명사는 반드시 중간에 넣는다.
	1. weak verb + 명사, 대명사 + 부사
	2. weak verb + 부사 + 명사

3. 구어체 : weak verb + to 부정사, -ing를 활용한 동적 문장 확장 선호 (80~90%)
	1. I got him to fix the car 
	2. 주어는 주로 사람(인물이 움직이는 동영상을 표현)
	3. We started to test the new system to see if it works.

4. 과거형 만들기 
	1. 불규칙 변화, 규칙변화 (-ed) 모두 존재 

#### strong verb 사용법

1. strong verb (transitive verb) 경우 
	1. 이미 접두사(prefix)에 전치사적 의미(in, out, to)를 품고 있으므로 전치사와 같이 쓰지 않는다.
	2. 예제
		1. enter : en- (in) + trare(cross) -> enter the room(O), enter in the room(X)
		2. discuss : dis- (apart) + quatere(shake) -> discuss the problem(O), discuss about the problem(X)

2. 문어체 : strong verb + 전치사구, p.p를 활용한 정적인 명사구 확장을 선호함(80~90%)
	1. The car was repaired by a technician.
	2. 주어는 주로 사물/개념/명사(결과만 정지되어있는 사진/스틸컷표현)
	3. The testing of the new system was initated for performance evaluation.

3. 과거형 만들기
	1. 규칙변화(-ed)만 존재(100%)


#### weak verb  VS strong verb

strong verb 
	- 구체적인 초점이 맞은 강력한 뜻을 가진다.
	- 딱딱하다.
	- 비지니스 이메일, 논문, 공식보고서, 뉴스
	- 라틴/프랑스계열 어원, 정적, 격식있다, 간결하다 
weak verb 
	- 그 자체로는 의미가 광범위하고 흐릿하다. 
	- weak verb에 강력한 무기인 조합을 이용하면 (weak verb + 전치사, 형용사, 명사, 준동사, 장소) strong verb 못지않은 구체성과 생동감을 준다. 
	- 말하기에 적합한 구조이다.
	- 일상대화, 소설, 스토리텔링, 실무미팅
	- 게르만계 어원, 동적, 생생함, 리듬감 있다. 

**따라서 용도에 맞게 사용해야한다.**






## - 라틴계와 게르만계 단어의 구조 

#### 1. 라틴어 구조 : 파생(Derivation)중심(접두사+어근+접미사)
1. 구조 : prefix(접두사) + Root(어근) + suffix(접미사)
2. 예시 : unpredictable
	1. un- : 게르만계/라틴계 혼용 부정 접두사, ~않는
	2. pre- : 라틴어 접두사, 미리
	3. dict : 라틴어 어근, 말하다 dicere
	4. -able : 라틴어/프랑스어 접미사, ~ 할 수 있는
	5. 뜻 : 예측할 수 없는(형용사)

#### 2. 게르만어의 구조 : 합성(Compounding)및 굴절(Inflexion)중심
1. 독립된 자립단어를 그대로 이어붙이는 복합어(합성어), 모음을 내부에서 바꾸는 굴절방식이 발달
2. 복합어 : compound words, 독립단어 + 독립단어
	1. tooth(치아) + ache(통증) = toothache(치통)
	2. day(낮) + break(깨지다/새다) = daybreak(새벽, 여명)
3. 모음교체(Ablaut) : 접미사 없이 단어 내부 변형
	1. man -> men(복수)
	2. drive -> drove (과거)
4. 게르만계 접미사/접두사 : 제한적이지만 존재
	1. 접두사 : un- (not), mis- (wrong), be- (강조)
	2. 접미사 : -ful (가득한), -ness(명사화), -hood(상태/신분)
	3. 예 : un-friend-li-ness (un- + friend(독립어근) + -ly + -ness)
